## Запуск проекта

Проект использует `json-server` для мокания backend API. В приложении настроен параллельный запуск frontend-части и mock-сервера.

1. Клонируйте репозиторий:
   Установите зависимости:

Запустите проект (клиент + mock-сервер):

```bash

npm start

```

Приложение будет доступно по адресу: http://localhost:5173
Mock API будет доступен по адресу: http://localhost:3001/tasks
