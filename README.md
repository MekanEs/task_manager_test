# Task Manager (Менеджер задач)

Современное веб-приложение для управления задачами, разработанное в рамках тестового задания.

## 🚀 Инструкция по запуску проекта

Для запуска проекта в режиме разработки выполните следующие шаги:

1. Клонируйте репозиторий и установите зависимости:

```bash
npm install
```

2. Запустите клиентскую часть и mock-сервер одновременно:

```bash
npm run start
```

- Либо отдельно:
  - Сервер: `npm run server`
  - Клиент: `npm run dev`

3. Откройте в браузере: `http://localhost:5173` (или порт, указанный Vite).

## 🛠 Описание используемых технологий

- **React 19** & **TypeScript** — библиотека пользовательского интерфейса и строгая типизация.
- **TanStack Query (React Query) v5** — эффективное управление серверным состоянием, кэширование и синхронизация мутаций.
- **React Router v8** — клиентская маршрутизация (страница списка задач и детальная страница задачи).
- **React Hook Form** + **Zod** — валидация форм и управление состоянием полей.
- **Tailwind CSS 4** — современная стилизация и адаптивный дизайн.
- **JSON Server** — легковесный mock REST API бэкенд.

---

## 🏗 Архитектура и принятые решения

Приложение построено с применением компонентного подхода и четкого разделения ответственности (SoC):

- `src/api/` — функции работы с API через Axios.
- `src/components/` — изолированные компоненты (карточки, формы, фильтры, модальные окна, обертки состояний).
- `src/pages/` — страницы приложения (В index lazy варианты, использутся для уменьшения начального бандла).
